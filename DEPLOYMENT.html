🚀 Guia de Deploy

Essência Íntima - E-commerce com Next.js, Supabase e Stripe

📋 Visão Geral

Este guia fornece instruções passo a passo para fazer deploy da loja Essência Íntima em produção usando Vercel, Supabase e Stripe.

✓ Projeto Pronto!
O projeto Next.js foi compilado com sucesso. Todas as dependências estão instaladas e configuradas.

✅ Requisitos

Antes de começar, certifique-se de ter:

  • Conta no GitHub
  • Conta no Vercel (gratuita)
  • Conta no Supabase (gratuita)
  • Conta no Stripe (gratuita para testes)
  • Node.js 18+ instalado localmente

1️⃣ Configurar GitHub

Passo 1.1: Criar Repositório

  1. Acesse github.com/new
  2. Nome: essencia-intima
  3. Descrição: Loja Online - Essência Íntima
  4. Clique em "Create repository"

Passo 1.2: Fazer Push do Código

cd c:\Users\Lenovo\Downloads\essencia-intima

# Adicionar repositório remoto
git remote add origin https://github.com/SEU_USUARIO/essencia-intima.git

# Renomear branch para main
git branch -M main

# Fazer push
git push -u origin main

2️⃣ Configurar Supabase

Passo 2.1: Criar Projeto

  1. Acesse supabase.com
  2. Clique em "New Project"
  3. Nome: essencia-intima
  4. Database Password: Salve em local seguro!
  5. Region: South America (São Paulo)
  6. Clique em "Create new project"

Passo 2.2: Copiar Credenciais

No dashboard do Supabase:

  1. Vá para Settings → API
  2. Copie Project URL → NEXT_PUBLIC_SUPABASE_URL
  3. Copie anon public key → NEXT_PUBLIC_SUPABASE_ANON_KEY
  4. Copie service_role secret → SUPABASE_SERVICE_ROLE_KEY

Passo 2.3: Criar Tabelas (SQL)

No Supabase SQL Editor, execute:

-- Tabela de Usuários
CREATE TABLE users (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  email VARCHAR UNIQUE NOT NULL,
  full_name VARCHAR,
  avatar_url VARCHAR,
  role VARCHAR DEFAULT 'customer',
  created_at TIMESTAMP DEFAULT NOW()
);

-- Tabela de Produtos
CREATE TABLE products (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  name VARCHAR NOT NULL,
  description TEXT,
  price DECIMAL(10,2) NOT NULL,
  image_url VARCHAR,
  category VARCHAR,
  in_stock BOOLEAN DEFAULT true,
  created_at TIMESTAMP DEFAULT NOW()
);

-- Tabela de Pedidos
CREATE TABLE orders (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  user_id UUID REFERENCES users(id),
  total DECIMAL(10,2),
  status VARCHAR DEFAULT 'pending',
  stripe_session_id VARCHAR,
  created_at TIMESTAMP DEFAULT NOW()
);

-- Tabela de Itens do Pedido
CREATE TABLE order_items (
  id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
  order_id UUID REFERENCES orders(id),
  product_id UUID REFERENCES products(id),
  quantity INTEGER,
  price DECIMAL(10,2),
  created_at TIMESTAMP DEFAULT NOW()
);

3️⃣ Configurar Stripe

Passo 3.1: Criar Conta Stripe

  1. Acesse stripe.com
  2. Clique em "Start now"
  3. Complete o registro
  4. Ative "Test mode" (canto superior direito)

Passo 3.2: Copiar Chaves API

No dashboard do Stripe (modo teste):

  1. Vá para Developers → API keys
  2. Copie Publishable key → NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY
  3. Copie Secret key → STRIPE_SECRET_KEY

Passo 3.3: Configurar Webhook

  1. No Stripe Developers → Webhooks
  2. Clique em "Add Endpoint"
  3. URL: https://seu-dominio.vercel.app/api/webhook/stripe
  4. Selecione eventos: checkout.session.completed, payment_intent.succeeded
  5. Copie Signing secret → STRIPE_WEBHOOK_SECRET
⚠️ Dica: Para testes locais com webhook, use stripe listen e copie o valor que aparecer.

4️⃣ Deploy no Vercel

Passo 4.1: Conectar Vercel com GitHub

  1. Acesse vercel.com
  2. Clique em "New Project"
  3. Clique em "Import Git Repository"
  4. Selecione seu repositório essencia-intima
  5. Clique em "Import"

Passo 4.2: Adicionar Variáveis de Ambiente

No formulário de configuração do Vercel:

Variável Valor (copie do)
NEXT_PUBLIC_SUPABASE_URL Supabase → Settings → API
NEXT_PUBLIC_SUPABASE_ANON_KEY Supabase → Settings → API
SUPABASE_SERVICE_ROLE_KEY Supabase → Settings → API
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY Stripe → Developers → API keys
STRIPE_SECRET_KEY Stripe → Developers → API keys
STRIPE_WEBHOOK_SECRET Stripe → Developers → Webhooks
NEXT_PUBLIC_URL Seu domínio Vercel (ex: essencia-intima.vercel.app)
NODE_ENV production

Passo 4.3: Fazer Deploy

  1. Clique em "Deploy"
  2. Aguarde a compilação (2-3 minutos)
  3. Seu site estará em essencia-intima.vercel.app

🔧 Troubleshooting

Erro: "NEXT_PUBLIC_SUPABASE_URL is not defined"

Solução: Verifique se você adicionou todas as variáveis de ambiente no Vercel

Erro: "Stripe API key not found"

Solução: Certifique-se de que a chave Stripe secreta está na variável STRIPE_SECRET_KEY

Checkout não redireciona para Stripe

Solução: Verifique se a chave pública do Stripe está correta em NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY
